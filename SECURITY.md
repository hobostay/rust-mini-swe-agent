# Security Policy

## Supported versions

This project is still evolving quickly. Security fixes are expected to land on `main` first.

## Reporting a vulnerability

Please do not open a public issue for security-sensitive problems.

If you find a vulnerability, report it privately through GitHub security advisories or contact the maintainer directly.

When reporting, please include:

- affected commit, branch, or release
- impact and attack scenario
- reproduction steps or proof of concept
- any relevant config, provider, or environment details

Areas that deserve extra care in this project include:

- command execution
- container and sandbox environments
- provider authentication and API key handling
- trajectory/log output that may contain secrets

I will review the report and respond as quickly as practical.
