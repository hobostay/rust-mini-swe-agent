# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added

- Rust reimplementation of the main `mini-swe-agent` CLI workflow
- `mini`, `bench`, `bench-single`, `inspector`, and `config` commands
- local, Docker, Singularity, Bubblewrap, and ConTree-compatible environments
- OpenAI-compatible chat/responses support plus OpenRouter, Requesty, and Portkey-compatible backends
- trajectory persistence and TUI inspector
- benchmark dataset loading from local files, remote JSON/JSONL, and Hugging Face dataset repos
- GitHub Actions CI
- issue templates, PR template, `CODEOWNERS`, and contributing guide
- ConTree config template, REST/API execution path, and environment tests
